Conhecendo o DOM

O que é o DOM?

DOM significa Document object Model.

É uma representação do documento HTML em forma de objetos, organizada em uma estrutura hierárquica de árvore, conhecida como DOM Tree.

Note que cada elemento do HTML está conectado. Chamados esses elementos de nó (node) dentro dessa estrutura.

Em outras palavras, o navegador basicamente transforma o HTML em uma estrutura

Pra que serve a DOM?

O DOM permite que o JavaScript interaja com os elementos HTML. Exemplos:

  • Selecionar elementos : Encontrar um botão
  • Alterar conteúdo: Alterar um título paragrafo...
  • Alterar estilos: Mudar cores, aplicar bordas e etc
  • Criar elementos: Criar paragráfos, listas, links e etc
  • Remover elementos: Exluir itens criados e já existentes
  • Capturar eventos: Detectar cliques, teclas pressionadas e etc
  • Capturar eventos: Alterar um src, um aria-label e etc.
